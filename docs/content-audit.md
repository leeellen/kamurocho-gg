## 수치의 의미

- 근거를 찾지 못한 구형 엔진 고유명 `Magical V Engine`은 확정된 엔진명으로 노출하지 않고 `Unverified`로 표시한다. `Dragon Engine (Enhanced)`의 근거 없는 버전 수식어도 제거했다.
- 플레이 시간은 편집 추정치다. 새로 측정하거나 통계 원자료를 확보한 값이 아니다.
- 달성률은 수집 시점의 Steam 공개 통계다. 이번 실시간 대조 대상은 업적의 키·이름·설명이므로 달성률을 실시간 검증했다고 주장하지 않는다.
- DB에 저장된 `신뢰도 0.95`는 사실 검증의 정확도를 뜻하지 않으므로 공개 표시를 제거했다.
- 업적별 어려움/쉬움 분류 역시 검증된 난이도라고 제시하지 않는다. 실제 달성률 표시는 유지한다.

## 반복 검사

```sh
pnpm audit:content
node --test tests/content-integrity.test.mjs
node --env-file=.env.local scripts/audit-content.mjs --verify-steam
```

기본 검사는 15개 게임의 데이터 등록, 업적 키, 두 언어 공략 존재 여부, 미니게임 연결, 출처 URL 형식, 지도 핀의 항목 대응·좌표 범위와 기록된 Steam 스키마의 지문을 검사한다. `--verify-steam`은 현재 Steam 스키마와 다시 대조한다. 인증키를 출력하거나 운영 DB를 수정하지 않는다.

- [Steam 대조 기록](content-verification.json): 게임별 업적 수, 안전한 공개 출처 링크, 대조한 필드의 SHA-256 지문.
- [전체 검사 결과](content-audit-results.json): 게임별 범위, 구조 검사 결과, 실시간 대조 여부, 페이지 응답 검사.
- [출처 응답 기록](source-link-audit.json): 현재 표시하는 출처 URL의 응답·제목·검사 시점. 같은 작업 중 확인한 URL은 이전 응답을 보존한다.

검사 스크립트의 DB·프레임워크 경계는 로컬 스냅샷을 사용하는 검사 어댑터로 대체한다. 별도로 실행한 프로덕션 페이지 검사는 실제 애플리케이션의 조회·대체 데이터 경로를 사용했다. 운영 DB를 변경하거나 배포하지 않았다.

## 아직 완벽하다고 판정할 수 없는 이유

1. 접근이 제한된 출처의 본문 전체는 확인하지 못했다. 접근 가능한 다른 출처와 검색에 노출된 부분만으로 확인한 주장도 있으며, HTTP 응답 검사는 본문 검증과 별개다.
2. 한국어판 실제 화면과 모든 대사·부품명·아이템명을 일대일 대조하지 못했다. 편집 번역과 공식 Steam 문자열을 구분했다.
3. 지도 좌표·피치별 공략·장기 수순 등 전체 세부 데이터를 실제 게임에서 재현하지 않았다. 구조 검사가 사실 검증이나 재현 검증을 대신하지 않는다.
4. Director's Cut 및 신판 앱과 구판 참고 공략 사이의 모든 세부 변경을 검증하지 못했다. 확인하지 못한 승계 동작 등은 확정적으로 안내하지 않는다.
5. 호출되지 않는 일반 공략 생성기의 희귀도 기반 추론은 이번 실행 경로에 포함되지 않는다. 재사용 전 별도 수정이 필요하다.

따라서 자동 검사 통과를 전체 콘텐츠의 완벽한 정확성으로 표시하지 않는다. 접근 가능한 자료의 대조를 계속하고, 한국어판 화면과 실행 재현이 필요한 항목은 미확인으로 남긴다.
